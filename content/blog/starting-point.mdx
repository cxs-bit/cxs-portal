This portfolio is a place to document what gets built and how it takes shape. The devlog starts here, with the portfolio itself.

## What goes here

Project updates will cover what changed, which decisions mattered, and what still needs work. As projects reach a point where there’s something to explore, they’ll get a home in the [project index](/projects).

## The foundation

The site uses Next.js, TypeScript, and Tailwind CSS. Posts are written as MDX alongside the code, so changes to the site and the notes about those changes can be reviewed together.
